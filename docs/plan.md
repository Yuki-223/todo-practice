# 待办清单实现计划

当前只有脚手架和 todos 表，不包含任何 CRUD 接口或交互。后续按以下顺序实现，每个任务完成后运行 lint、typecheck 和 test。

1. **查询与展示**：实现服务端查询，按创建时间倒序、id 倒序展示；空列表显示引导文案。
   - 验证：临时 SQLite 数据库分别放入 0 条和多条记录，断言查询结果和排序；页面检查空态及列表显示。
2. **新增待办**：增加输入框与服务端新增操作，去除首尾空格，拒绝空标题和超过 200 字的标题。
   - 验证：测试合法输入持久化，空白和超长输入无写入；页面新增后立即显示，刷新后仍存在。
3. **完成状态切换**：支持完成与取消完成，服务端校验 id，记录不存在时返回明确错误。
   - 验证：测试 false → true → false 的数据库状态，以及无效和不存在的 id；刷新后状态保持。
4. **修改标题**：支持编辑、保存和取消，复用新增时的标题校验。
   - 验证：测试有效更新、无效输入保留原值；页面取消不保存，保存后刷新显示新标题。
5. **删除待办**：支持删除单条记录，明确处理记录不存在的情况。
   - 验证：测试只删除指定 id，其余记录不变；页面删除后消失，刷新后不再出现。
6. **筛选与集成验证**：支持全部、未完成、已完成筛选，将筛选条件保存在 URL 中。
   - 验证：混合状态数据分别断言三种筛选结果，未知参数回退到全部；手动走通新增、修改、完成、筛选、删除，检查空态与错误提示。
